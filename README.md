📊 Seaborn Data Visualization Practice

This repository contains my practice work on **Data Visualization using Python**, mainly using **Seaborn, Matplotlib, and Pandas**.

The practical is based on the popular **Seaborn Tips dataset** and covers different types of plots used for Univariate, Bivariate, and Multivariate Data Analysis.

---

🎯 Objectives

- Understand different data visualization techniques
- Learn how to create plots using Seaborn and Matplotlib
- Analyze relationships between numerical and categorical variables
- Understand distributions and identify outliers
- Perform basic exploratory data analysis (EDA)
- Interpret visualizations and extract meaningful insights

📌 Types of Analysis

Univariate Analysis
Analysis of a single variable.

Examples:
- Histogram
- Box Plot
- Count Plot
- KDE / Density Plot
- Pie Chart

Bivariate Analysis
Analysis of two variables.

Examples:
- Scatter Plot
- Bar Plot
- Box Plot
- Violin Plot

Multivariate Analysis
Analysis of more than two variables.

Examples:
- Pair Plot
- Heatmap
- Scatter Plot with Hue
